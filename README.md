# Granny-Escape-Together-Optimized
## Installation

1. Download the optimization files
2. Extract the ZIP file
3. Press `Win + R`
4. Enter:

`%LOCALAPPDATA%\GrannyEscapeTogether\Saved\Config\WindowsNoEditor`

5. Press Enter
6. Copy the optimization files into this folder
7. Replace the existing files if Windows asks
8. Launch Granny: Escape Together

The game should now use the optimized configuration
